# Lamari

Новий інтернет-магазин прикрас. Проєкт ізольований у цій папці; жодних змін на
основному домені не виконується без прямого підтвердження власника.

## Поточний статус

Етап 1 — локальний MVP. Підготовлено:

- [технічний план](docs/TECHNICAL_PLAN.md);
- [структуру бази даних](docs/DATABASE.md);
- [список інтеграцій](docs/INTEGRATIONS.md).
- [інструкцію запуску та handoff](docs/HANDOFF.md).
- [скриншоти локального MVP](docs/screenshots/).

Реалізовано storefront, guest checkout, fake payment, базову адмінпанель і
автоматичні тести. Захищений staging розгорнуто 2026-07-29; production не
розгортався.

## Правило розгортання

1. Розробка локально в `lamari/`.
2. Перше розгортання — тільки тестове середовище з окремою БД, сховищем,
   платіжними sandbox-ключами та забороною індексації.
3. Публікація на основному домені — лише після письмового підтвердження власника.
